# 发布会风格 PPT 生成器 — PoC 设计

日期：2026-10-11 · 状态：PoC

## 目标
输入一句话主题和补充说明，生成新品发布会风格的图片版 .pptx（每页一张全屏 16:9 AI 生成图，第一版不要求可编辑）。

## 关键决策
- **整页 AI 生图**：百炼 `qwen-image-3.0`，同步接口 `multimodal-generation/generation`，尺寸 `2048*1152`（16:9）。
- **风格一致性（方案 B）**：先生成封面，用户确认并“锁定风格”后，其余页以封面为参考图走图生图，提示词中声明“只沿用风格，不沿用构图与文字”。
- **文案与提示词**：百炼 `qwen-plus`（OpenAI 兼容接口）一次输出 `style_guide` 和逐页大纲 `slides[]`。每页包含 type / title / subtitle / visual 四个字段。标题和副文案尽量短，降低生图时的文字错误率。
- **风格**：4 个预设，外加一段自定义文字描述（可与预设叠加，也可单独使用）。
- **形态**：本地 Web。后端 FastAPI，前端为单个 HTML 页面 + 原生 JS；数据存在本地 `projects/<id>/project.json` 及图片文件中。
- **导出**：`python-pptx`，每页一张全屏图片，并把标题和副文案写进备注。

## 流程
1. 输入主题、补充说明、风格、页数 → 生成大纲
2. 在界面上编辑大纲（改字、增删页、调整顺序）
3. 生成封面 → 可附修改意见重抽 → 锁定风格
4. 批量生成其余页（并发 3），可单页重抽 → 导出 PPTX

## 不在 PoC 范围内
自动 OCR 文字校验、可编辑文本层、用户登录、多用户。

## Mock 模式
`MOCK_MODE=1` 时，LLM 和生图都返回本地占位结果，用于在没有 API Key 时演示和测试整个流程。
